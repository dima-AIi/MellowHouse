# Перенос Mellow House на React и TypeScript

29.10.2026. Этап 1. База сравнения — commit `66e916edb065fda511b577e9fb522caa99028076`.

## Ограничения пользователя

Сохранить нынешний дизайн и всё существующее поведение. Не менять данные, заказы, пользователей, цены, правила оплаты и статусы ради переноса интерфейса. Сохранять прямые ссылки и запуск установленного приложения с главной.

## Перенесено

- Общая шапка и подвал; существующее мобильное меню и анимация подключаются после создания шапки.
- Категории, карточки, популярные товары, рекомендуемое и избранное; счётчики и доступность используют общую корзину.
- Поиск по названию и ингредиентам с сохранением запроса при возвращении из карточки.
- Страница товара, связанные товары, состав, аллергены и русское КБЖУ в раскрывающемся блоке.
- Настройки товара в карточке, редактировании корзины и помощнике: radio/checkbox, обязательность, минимум/максимум, подписи цены. Radio-группы разных окон имеют разные имена.
- FAQ и справочник состава/аллергенов.
- AI-чат: карточки всех запрошенных категорий, добавление конкретной позиции, конфигурация, продолжение после перехода, повтор с прежним requestId, очистка при смене владельца.

## Что намеренно использует прежнюю реализацию

Авторизация, корзина, оформление, платежи, страница заказа, профиль и админка. Это рабочие части проекта, а не заглушки. Их последовательный перенос — следующие этапы. Не объявлять весь сайт или старые JS-контроллеры полностью переписанными на React/TypeScript.

## Совместимость и публикация

- Те же URL, cookies, CSRF, ключи браузерной корзины и формат истории чата.
- Один `core.js` на странице. React не создаёт второй клиент/вторую корзину.
- React владеет только помеченными `data-react-component` контейнерами; старые функции перестают менять их содержимое. Оформление и оплата продолжают использовать действующий сервер.
- Серверный HTML остаётся доступным до загрузки JavaScript. Ошибка загрузки bundle включает прежний интерфейс.
- Сборка Node 24 + pnpm с lockfile включена в Docker, Vercel и GitHub Actions; затем выполняются существующие проверки.
- Статическая витрина Vercel остаётся независимой от запуска Render; окончательная проверка цены и отправка заказа требуют сервера, как до переноса.
- Откат: вернуть предыдущий deployment/commit. Миграции БД и преобразование данных не требуются.

## Проверки первого этапа

Автоматически: строгая проверка TypeScript, production-сборка; тесты React карточек, поиска, экранирования текста, ограничений и изоляции настроек; тесты чата, точного выбора карточки, повторного requestId и восстановления после навигации. Также вся действующая серверная и браузерная проверка.

В браузере локально: поиск сырников; добавление; выбор соуса отдельно; открытие корзины; редактирование и объединение одинаковых конфигураций (2 порции, 640 ₽); открытие гостевого оформления с верной суммой; подбор кофе и пиццы в новом чате; переходы через контакты с восстановлением диалога; мобильное меню и каталог при ширине 390 px. Реальные деньги и реальные заказы в проверках не использовались.

Границы проверки: физическая установка PWA и поведение на реальном iPhone/Android требуют проверки на устройствах. Нельзя гарантировать отсутствие всех возможных ошибок по одному успешному набору тестов.
