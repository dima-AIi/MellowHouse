# Решения

- Основной стек без отклонений: .NET 10, Razor Pages, EF Core, собственные CSS и ES modules. Один origin и один запуск.
- Деньги хранятся целыми рублями (демокаталог без копеек); сервер рассчитывает каждую конфигурацию. Представление допускает будущий переход к копейкам через единую функцию.
- Палитра #FFFFFF / #123F32 / #E8F2ED / #218354. Кириллический Oswald для заголовков и Golos Text для текста, локальные файлы с OFL.
- Все 8 макетов — один сайт; служебные подписи раскадровки не переносятся.
- Гостевой идентификатор — защищённая HttpOnly cookie; корзина/избранное в БД. После входа объединяются с профилем.
- Локальный код 123456 разрешён только Development. В Production изолированный демопрофиль привязан к случайному секрету браузера и не открывает чужой профиль по номеру.
- Демо-платёж фиксирует отдельную попытку, успех атомарен, номер заказа уникален. История хранит снимки цен и конфигураций.
- Публикация подготовлена, но не выполняется до подключения аккаунта пользователем.

- Последнее уточнение пользователя: два товара сейчас, 10 категорий; полный каталог сохранён в staging. Товарные фото с alpha, окружение только для hero, категорий и рекламных блоков.
