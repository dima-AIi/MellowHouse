# Мобильная версия Mellow House

- Боковое меню: выезд за 650 мс, затемнение, понятный заголовок, активный раздел, закрытие кнопкой, снаружи и Escape. Нативный dialog удерживает фокус; reduced-motion отключает анимацию.
- Карточки меню: фото 112 px, компактные названия, вес и цена. Описание доступно внутри товара. Популярные блюда на главной — по две небольшие позиции в ряд, фото 118 px.
- Подвал: три сворачиваемых раздела на телефоне, открытые колонки на компьютере. Вместо больших неработающих значков платформ — ссылка установки сайта. Нижний отступ защищает ссылки от закреплённой корзины.
- Кнопка приложения на компьютере: готовая иконка окна и подпись «Приложение». В установленном режиме скрыта лишняя ссылка установки в подвале, уменьшен первый экран и убрано видео-вступление меню.
- Основные 15 иконок заменены на Lucide; лицензия ISC/MIT сохранена в wwwroot/images/lucide-LICENSE.txt. Внешних запросов при использовании иконок нет. URL спрайта версионирован для обновления кэша.
- По просьбе владельца добавлено ограничение масштаба viewport и обработки жеста Safari; поля имеют размер 16 px против автоматического увеличения при вводе. Браузеры могут самостоятельно сохранять возможность пользовательского масштабирования.

Проверка: успешная сборка Razor без предупреждений; 29 JavaScript-проверок; визуальная проверка на ширине 390 px: карточки, открытие/закрытие меню, разделы подвала. Версия HTML/экспорта/кэша 20 согласована. Реальное установленное приложение на физическом телефоне требует проверки владельцем: правила standalone заданы отдельно, браузерная проверка не подменяет тест устройства.
