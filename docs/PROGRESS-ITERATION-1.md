# Mellow House — ход реализации

Актуальный объём: два демонстрационных товара, все 10 разделов и все покупательские сценарии. Массовое наполнение отложено по последнему сообщению пользователя; исходные материалы сохранены.

## Выполнено
- Прочитаны обязательные документы; просмотрены все 8 финальных PNG и 9 референсов.
- Созданы MellowHouse.sln, .NET 10 Razor Pages, C#, EF Core, SQLite и отдельные PostgreSQL-миграции. Для F5 не нужны frontend-сервер и Docker.
- Реализованы главная с тремя эффектами, горизонтальные популярные товары, статичные фотокатегории, длинное меню, товар, корзина и правка, вход, оформление, демо-оплата и результаты, история, избранное, рекомендации, профиль/адрес, информационные страницы, PWA и общий подвал.
- Каталог содержит только ванильный раф и сэндвич BBQ с курицей. Пустые категории показывают «Скоро в меню». Структурированный JSON позволяет добавлять товары без переделки страниц.
- Подготовлены отдельные фотографии с настоящим alpha для двух товаров, собственные фото hero/категорий/рекламы, локальные шрифты и лицензии. ASSET-SOURCES.md содержит источники и условия.
- Сервер проверяет опции и цену; корзина/избранное/вход/черновики/заказы сохраняются в SQLite. Демо-платежи идемпотентны, история хранит снимки.
- Debug и Release собраны без предупреждений и ошибок, publish подготовлен. Сборка через установленную Visual Studio успешна.
- Серверные тесты: 18 пройдено, 0 ошибок/пропусков. Финальная браузерная проверка: 75 основных + 28 краевых + 4 загрузки = 107 успешных утверждений.
- Сохранены актуальные скриншоты, сравнение всех восьми макетов, отчёт VERIFICATION.md и обзор доступности. Проверены 390/768/1024/1440 px и reduced motion.
- README-RU.md и DEPLOY-VERCEL-RU.md подготовлены. Проверочный localhost-сервер остановлен для запуска из IDE.

## Исправленные ошибки
EF tracking новой CartLine и повтор строки в JSON, HTML option кафе, фокус количества, отмена удаления в диалоге, устаревшие ошибки полей, пропорции категорий, фото hero, преждевременная отправка во время загрузки. В тестовых скриптах исправлены ожидание ответа добавления и снятие активного перехвата. Итоговые наборы прошли полностью.

## Ограничения проверки
- F5/Ctrl+F5 в самом окне IDE не нажимались: проверены devenv-сборка и тот же launch profile через dotnet. В повторном devenv был диагностический сбой фонового NuGet; отдельные restore + build через MSBuild Visual Studio прошли с кодом 0. Точная причина сообщения IDE не доказана, сведения и штатное восстановление записаны в VERIFICATION.md/README-RU.md.
- IAB не подключился к localhost, native computer-use остановлен защитой определения URL. Сайт проверен отдельным Chrome через Playwright без пользовательского профиля.
- Docker/PostgreSQL и публичный Vercel не запускались. Настоящие платежи/SMS не подключены и не входят в демонстрацию.
