# Исправление интерфейса после полного переноса на React

31.10.2026. Версия витрины 27.

## Что исправлено

- Убрана подпись «Время для любимого» из React и начального серверного HTML меню.
- Убраны заголовок «1 Получение» и номер перед способом оплаты.
- Серверные ошибки timing и scheduledLocal показываются непосредственно в группе «Время получения». Группа получает фокус и прокручивается в видимую область; сообщение не дублируется внизу формы. Изменение времени очищает исправляемую ошибку.
- В админке возвращены прежние карточки товаров и категорий, отдельные кнопки «Изменить», «Дублировать», «В архив», поиск, сортировка и переключение архива. Черновики и стоп-лист доступны через фильтр. Архивация снова требует подтверждения, восстановление сохранено.
- Личный кабинет снова использует account-grid: боковая навигация слева, вкладки и содержимое справа. Восстановлены подсказка возраста и подтверждение сохранения профиля. Сохранение недоступно до загрузки прежнего адреса, чтобы не затереть его пустыми полями.

## Запуск и новые вкладки

/api/state уже содержит актуальную корзину — повторный GET /api/cart удалён из запуска. Админка получает состояние сессии и загружает свой раздел, не ожидая публичного каталога. Публичный каталог и общедоступные настройки сохраняются отдельно от сессии; ни профиль, ни заказы, ни серверная корзина, ни CSRF в этот кэш не попадают.

При открытии вкладки сохранённое меню можно сразу показать без исчезновения карточек. Обновление каталога не блокирует готовность сессии. Быстрое подключение не вызывает вспышки баннера: сообщение появляется только после 2,5 секунды ожидания либо при ошибке. Во время короткой загрузки в шапке не показывается ложная пустая сумма корзины. Профиль и админка сохраняют навигационную оболочку при загрузке данных.

Это сокращает лишнюю работу клиента. При фактически недоступном сервере отправка заказа и оплата по-прежнему требуют соединения; меню и локальная корзина остаются доступны. Изменений базы данных и правил графика кафе нет.
