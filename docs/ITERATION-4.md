## Проверки
46/46 серверных тестов. Browser/computer-use: вход по почте, сохранение профиля/reload, активные вкладки, рекомендуемое/избранное без hero, добавление/изменение/архив расхода, CSV, неделя/месяц, прямой статус «Готов», реальные ответы AI, полный цикл видео, 390 px. Найденные браузером ошибки счётчика сводки и позиции рекомендуемого исправлены и проверены повторно.

Сохранность: artifacts/preservation-v4.json. 64 заказа =50 примеров +14 пользовательских; снимки пользовательских заказов, оплаты, товары, категории, корзины, избранное, ключи и реквизиты сохранены. Изменился только идентификатор входа администратора на почту, ID/хеш пароля прежние. Имеются штатные EF миграции для SQLite/PostgreSQL. PostgreSQL SQL обновлён; живой PostgreSQL и внешний deployment проверяются при публикации.
