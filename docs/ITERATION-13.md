# Публичная витрина без ожидания Render

Причина отличия от Portfolio Platform подтверждена HTTP-ответами: портфолио отдаёт статический HTML и `/assets/index-CuKaPHw7.js` прямо с Vercel (`X-Vercel-Cache: HIT`), а прежняя конфигурация кафе перенаправляла все пути на Render.

Витрина кафе переведена на статическую публикацию Vercel. Node-экспортёр собирает публичные страницы и каталог из анонимных ответов Render, копирует файлы из `wwwroot` и формирует Build Output API v3. Админка и API остаются на Render без кеширования. Закрытые данные и токены в статическую сборку не попадают.

Клиент читает опубликованный каталог сразу, поддерживает поиск и настройку товара до соединения с API, затем получает реальную сессию, актуальные товары, цены и настройки. Повторяются только безопасные стартовые GET-запросы; оформление и прочие изменения повторно автоматически не отправляются.

Бесплатный Render по-прежнему может засыпать: устранено ожидание при открытии витрины, но серверные действия могут ждать запуска. Во время этого ожидания видна ненавязчивая строка подключения. Пока API не ответил, показан каталог на момент публикации. Для постоянно актуального каталога без такого промежутка нужен работающий сервер либо дополнительный механизм публикации обновлений.

Изменения не требуют оплаты или изменения проектов портфолио. Используется существующая база и тот же публичный адрес.
