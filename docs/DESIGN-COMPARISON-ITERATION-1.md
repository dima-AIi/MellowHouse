# Сверка с утверждёнными макетами

Все восемь PNG из Mellow-House-Handoff/02-design просмотрены инструментом view_image. Сравнение выполнено с реальными скриншотами из изолированного Chrome, а не с изображениями сгенерированного сайта.

**Приоритет последнего уточнения:** два товара вместо полного наполнения; прозрачные товарные фото вместо прежних фотографий с окружением. Эти отличия намеренные и не являются пропущенными разделами. Все 10 разделов существуют, пустые имеют состояние «Скоро в меню».

Фотографии не повторяют пиксели исходных макетов: это собственные ассеты. Служебная раскадровка, подписи альтернативных состояний и случайные числа из PNG в клиентский интерфейс не перенесены. Финальные дополнительные блюда и рекомендации появятся вместе с наполнением, без изменения структуры страниц.
