# Итерация 28 — замечания аудита

- Пустой поиск: заметное сообщение «Результаты не найдены», подсказка и восстановление результатов при следующем запросе.
- Телефон: проверка до ожидания сервера; ошибка у поля, фокус, запрет букв и лишних цифр. Сохранены форматы +7/8 и обычные разделители.
- Контраст ссылки «Приложение»: явные цвета #123f32 на #edf4ef, включая состояние наведения.
- Производительность: семь файлов CSS объединены и минифицированы Vite; профиль, оформление, заказы и помощник вынесены в отдельные чанки; помощник загружается при приближении к чату.
- Главный баннер: ранний preload с учётом ширины экрана. Мобильное изображение уменьшено 135446 → 78906 байт; настольное 271796 → 153472 байт.
- Изображения категорий: варианты WebP 320/480/640 для React и начального HTML. Загруженные пользователем изображения сохраняют прежний путь.
- Шрифты: те же начертания и наборы символов, WOFF2 вместо TTF, общий размер 356380 → 148188 байт.
- Сборка Docker получает CSS-исходники; кэш и экспорт обновлены до v28.

Проверка: 62 теста React, 36 Node; сборка TypeScript/Vite. В браузере проверены пустой поиск, ошибка телефона и сохранение оформления. Итоговый балл PageSpeed зависит от отдельного нового запуска и не гарантируется числом внесённых изменений.
