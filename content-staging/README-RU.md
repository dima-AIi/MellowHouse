# Исходный план меню

catalog-full.json и CATALOG-FULL.md сохраняют исходный согласованный план 73 товаров/10 категорий. После просьбы пользователя от 21.10.2026 все эти позиции включены в наполнение базы; ещё пять новых напитков доводят ассортимент до 78.

Файлы заполнения: Data/catalog.json (2 исходных товара), Data/catalog-expanded.json (30), Data/catalog-completion.json (46). Источник сайта после первичного заполнения — БД. Повторный запуск не перезаписывает изменения администратора и не восстанавливает архивированные товары.

Новые файлы изображений находятся в wwwroot/images/products/*-v6.png. Их происхождение и точные промпты — docs/asset-manifest.json, правила подачи — docs/PRODUCT-PHOTOGRAPHY.md. Исходники в artifacts/assets-original/ сохранены. Итоговый каталог — docs/CATALOG.md.
