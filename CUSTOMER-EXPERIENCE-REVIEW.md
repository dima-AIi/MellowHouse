# Проверка сайта от лица клиента — 21 октября 2026

Проверка выполнена в браузере на отдельной копии базы: реальные товары и заказы не изменялись ради тестов. Проверялись обычный экран и ширина 390 px. После публикации отдельно проверяется публичный сайт.

## Пройденные действия

| Сценарий | Результат |
| --- | --- |
| Найти блюдо по категории, открыть карточку, вернуться к меню | Работает; КБЖУ убраны из списка, находятся в раскрывающемся разделе товара |
| Найти «матча» | В выдаче три напитка с ценой и ссылкой на товар |
| Добавить порцию, увеличить и уменьшить количество | Работает прямо в карточке; количество и сумма корзины синхронизируются |
| Изменить количество товара с разными рецептами | Открывается корзина для выбора конкретного рецепта; случайный вариант не меняется |
| Сохранить товар в избранное и открыть избранное | Работает; на динамической карточке есть тот же счётчик |
| Переключить доставку на самовывоз и перейти к оформлению | Выбран самовывоз, адрес доставки не требуется, доставка бесплатна |
| Вернуться на доставку в оформлении | Адрес снова доступен; стоимость доставки возвращается в итог |
| Открыть историю и подробности заказа | Видны состав, оплата и отдельная последовательность статусов получения |
| Спросить помощника «Что я ел вчера?» | Проверяется собственная история; при отсутствии записей помощник сообщает об этом с конкретной датой |
| Уточнить «А в среду?» | Используется предыдущая среда, показана дата; чужие заказы недоступны |
| Запросить последний заказ и нажать «Добавить» у блюда | Показаны реальные позиции из истории и текущие цены; добавлено только выбранное блюдо |
| Раскрыть FAQ и пищевую ценность | Ровные отступы, читаемый текст, понятные «+ / −», работают мышь и клавиатура |
| Открыть меню и избранное на телефоне | Нет горизонтального переполнения; широкая строка «− число +» помещается в карточке |

## Что исправлено во время этой проверки

- КБЖУ перенесены в товар: состав, аллергены и пищевая ценность собраны в одном блоке.
- В каталоге, популярных и избранном появился полноценный счётчик. Уменьшение последней порции убирает позицию; существующий рецепт сохраняется.
- Вопросы об истории обрабатываются до общего фильтра тем. Данные берутся на сервере только для текущего пользователя и не отправляются внешней языковой модели.
- Помощник различает заказ и факт приёма пищи: пишет «вы заказывали». Незавершённая онлайн-оплата не выдаётся за выполненный заказ. Недоступные блюда не предлагаются к добавлению.
- Гостю предложен вход прямо из чата с продолжением вопроса после входа.
- Длинный ответ начинается с текста, а не с последней карточки. Высота чата ограничена относительно экрана.
- Исправлены отступы FAQ и оформление разделов товара. Тот же FAQ используется на странице доставки.
- Надпись «Скачать приложение» заменена на «Сайт на главном экране»: ссылка ведёт к существующей инструкции установки сайта.

## Проверки корректности

- Полный набор: 73 серверных теста, 0 ошибок; 4 клиентских теста статусов, 0 ошибок.
- После уточнения обработки дней недели повторно пройдены 5 целевых тестов истории, корзины и размещения КБЖУ.
- Проверена изоляция пользователей: нельзя получить чужую историю или изменить чужую корзину.
- Проверены незавершённая оплата, отсутствие заказов, сохранение настроек напитка, неоднозначные рецепты и удаление последней порции.
- JavaScript проверен на синтаксис. Сборки Debug и Release — без предупреждений.
