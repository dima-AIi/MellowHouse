# React + TypeScript — Mellow House

Весь интерактивный интерфейс работает на React 19 и строгом TypeScript. Сервер ASP.NET Core, база и API сохранены. Старые контроллеры core/site/admin не загружаются новой витриной или панелью.

## Запуск

Node.js 24, pnpm 11.25.0 и .NET SDK из global.json:

```powershell
pnpm --dir frontend install --frozen-lockfile
pnpm --dir frontend build
dotnet run --project src/MellowHouse.Web
```

`pnpm --dir frontend dev` пересобирает интерфейс при изменениях. ASP.NET обслуживает bundles из wwwroot/react на том же origin, что API и cookies. `check` проверяет типы, `test` запускает Vitest/Testing Library.

## Модули

- public-app / chrome / components — страницы витрины, поиск, категории, карточка, КБЖУ, FAQ, мобильная навигация и установка PWA.
- store / browser-cart / sessions — запросы, CSRF, состояние, сохранение корзины до запуска сервера, последовательные изменения, защита от старых ревизий, приватные ссылки и история чата.
- cart-auth / checkout / orders / account — вход, корзина, гостевое оформление, оплата, отслеживание, отмена, профиль и повтор заказа.
- assistant — диалог, подходящие подсказки, все запрошенные блюда, настройки и добавление.
- admin-app / admin-catalog / admin-orders / admin-people / admin-report — полная панель: каталог, фотографии, опции, категории, заказы, статусы, возвраты, ручной заказ, клиенты, расходы, CSV, настройки и аудит.
- ui — доступные формы, native dialog, защита повторного действия и обработка ошибок; types / admin-types — DTO.

Информационные тексты About/Contacts/Delivery/App/Legal сохраняются из доверенного серверного HTML и выводятся React-компонентом. Скрипты и приватные токены из этого фрагмента удаляются. Это содержимое страниц, а не старые JS-контроллеры.

## Публикация

Docker, Vercel и GitHub Actions собирают исходники с lockfile. Bundles и node_modules не коммитятся. Vercel обслуживает публичную статическую витрину; API и приватные страницы обслуживает Render. Меню и сбор корзины доступны до подключения сервера; цены и заказ окончательно проверяет сервер.

Серверная разметка остаётся начальным экраном и доступна для чтения при ошибке скачивания JS. Bootstrap показывает повтор загрузки; старый интерфейс не подмешивается. Исторические JS-файлы сохранены для совместимости старых версий и регрессионного сравнения.

Оплата и выдаваемые коды входа сохраняют существующий демонстрационный режим. Перенос UI не подключает банк, SMS или рассылку.
