## Запуск в Visual Studio
1. Откройте **D:\дима\MellowHouse\MellowHouse.sln** в установленной Visual Studio Community 2026.
2. Стартовый проект — **MellowHouse.Web**, профиль **MellowHouse**. При необходимости назначьте проект запускаемым через его контекстное меню.
3. Нажмите **F5** или **Ctrl+F5**. Адрес — **http://localhost:5186**. Проверка БД — **/health**.
4. Development применяет миграции автоматически. Повторный запуск сохраняет данные и изменения администратора.

Приложены launchSettings.json и MellowHouse.slnLaunch. Основной HTTP-профиль не требует сертификата. Для HTTPS-профиля пользователь может отдельно доверить dev-сертификат штатными средствами; настройки безопасности не изменялись. Если порт занят собственным предыдущим запуском, остановите его перед F5.

Debug/Release проверены MSBuild установленной VS; devenv собрал оба проекта. При командном старте devenv сохранилось предупреждение фонового NuGet «не удалось загрузить подробности для проекта», хотя итог сборки успешный. MSBuild /restore проходит. При таком сообщении в IDE дождитесь загрузки решения, выполните «Восстановить пакеты NuGet», затем сборку. Нажатие F5 в окне IDE в этой среде недоступно и не объявляется проверенным.

## Клиентский вход
- Корзина и избранное доступны гостю и объединяются с данными профиля при входе.
- **Телефон:** тестовый российский номер, код **123456** в Development. SMS не отправляется. Нормализация 8/+7, строго 11 цифр.
- **Почта:** «Почта и пароль» → «Создать аккаунт». Пароль от 10 символов, с буквой и цифрой. Дальнейший вход — по почте и паролю. Стандартный PasswordHasher ASP.NET Core хранит только хеш.
- Старый почтовый профиль первой итерации нельзя захватить повторной регистрацией: администратор выдаёт ссылку восстановления.
- «Не помню пароль» создаёт локальную инструкцию в **src/MellowHouse.Web/App_Data/mail/**. Ссылка одноразовая, 30 минут. Настоящие письма не отправляются. Для другого порта замените origin, сохранив фрагмент после #.
- В Production телефонный сценарий остаётся изолированной демонстрацией по браузеру. Настоящие SMS и подтверждение почты подключаются перед реальным использованием. Для разработки используйте синтетические контакты.

## Вход администратора
Из шапки сайта: **«Войти» → «Почта и пароль»**. Почта локального администратора — **admin@mellowhouse.local**, пароль остался прежним. Точные реквизиты — `src/MellowHouse.Web/App_Data/admin-access.json` (поля email/password). Отдельная /Admin/Login принимает ту же почту и пароль. Вкладка «Администратор» удалена из клиентского окна. У существующей учётной записи сохранены ID, хеш пароля, права и заказы; добавлена почта. Файл реквизитов исключён из Git и публикации. Для нового размещения задайте Admin__Email и Admin__Password через серверные секреты.

На основном сайте администратор видит в профиле «Панель управления». Гость и обычный клиент не имеют доступа к страницам и API панели. Пять разделов:
- **Обзор и отчёты:** период МСК, финансовая сводка, очередь, оплаты/возвраты, товары и CSV. Вкладка «Финансы и расходы» позволяет добавлять/изменять/архивировать операционные расходы и экспортировать их. Неизвестная себестоимость не заменяется нулём; прошлое не пересчитывается по сегодняшним ценам.
- **Каталог:** товары/категории, поиск/сортировка, создание категории внутри товара, черновики, архив/восстановление, визуальный конструктор опций, прозрачные PNG.
- **Заказы:** очередь/история/ожидающие оплаты/возвраты, детали и настройки, принятие/отказ, приготовление/готовность/курьер/завершение, ручной заказ и фиксация оплаты при получении.
- **Гости и команда:** поиск, история, даты и активность за последние 5 минут, блокировка с прекращением сеанса, одноразовая ссылка восстановления. Пароль телефонному профилю не приписывается. Единственного активного администратора нельзя заблокировать.
- **Настройки:** кафе/контакты/доставка, способы оплаты, тексты/ролик/FAQ, журнал действий. Неизвестные адрес и график не выдуманы.

Reset-ссылка показывается администратору один раз, в БД — хеш токена. После смены пароля старый пароль и сеансы перестают действовать.

## Оплата и обработка
Карта, СБП, ЮMoney, наличные/карта при получении. Операции локальные, **реальных списаний/перечислений нет**; банковские реквизиты не запрашиваются. IPaymentProvider подготовлен для будущего провайдера. ЮKassa сейчас не подключена.

QR содержит обычный текст MELLOWHOUSE:ORDER:<id>:TEST, без URL и реквизитов. Ошибка/отмена/смена метода/повтор не дублируют заказ. При получении заказ поступает неоплаченным; сотрудник отдельно отмечает оплату. Завершить неоплаченный заказ нельзя. Отклонение не возвращает деньги автоматически.

Возврат — отдельная локальная операция по оставшимся позициям/доставке с причиной, историей и защитой от повтора. Платёж и выполнение хранятся отдельно. Статус в деталях заказа покупателя обновляется периодически.

### NVIDIA AI
Ключ находится только в `src/MellowHouse.Web/App_Data/assistant-secrets.json`, вне исходников и публикации. Файл уже настроен на этом компьютере. Рабочий endpoint — `https://integrate.api.nvidia.com/v1/chat/completions`, модель — `openai/gpt-oss-20b` через NVIDIA. Альтернативы сравнивались на реальных запросах; устаревшая Llama возвращает 410, поэтому не используется. Новые пакеты не потребовались: HttpClient и System.Text.Json входят в .NET 10.

Для другого окружения задайте `Assistant__ApiKey` и `Assistant__Model` через серверные секреты. Не добавляйте ключ в JavaScript, appsettings общего доступа или репозиторий. При отсутствии ключа либо ошибке/таймауте API работает помощь по локальному каталогу. Настроенный провайдер отображается в «Настройки → Контент и FAQ»; это признак настройки, а не непрерывный мониторинг доступности.

Помощник отвечает о Mellow House, использует текущие товары/цены/опции/FAQ и до 4 предыдущих вопросов этой вкладки. Посторонние темы и попытки отменить правила отклоняются. Профили клиентов, история заказов и реквизиты оплаты не включаются в контекст. Ответ выводится текстом, ID сверяются с каталогом. Добавление выполняется только кнопкой после настройки, оформление и платёж — обычным подтверждённым сценарием сайта. Внешний сервис требует интернета и доступного лимита NVIDIA; ключ нельзя публиковать.
